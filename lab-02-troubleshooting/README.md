# Lab 02: IT Troubleshooting

## Objective
Practice documenting technical investigation and incident
outcomes for common IT support problems.

## Scenario 1 — Printer
## Incident Details
- Incident number: INC00100011
- Short description: Printer not responding to print jobs
- Platform: ServiceNow Personal Developer Instance

## Reported Symptom
The fictional user reports that print jobs are not completing.

## Troubleshooting Procedure
1. Identify the scope of the issue by determining whether one user or multiple users are affected.
2. Check the reported printer status for signs that it may be offline or unavailable.
3. Review the simulated print queue for jobs that are pending or stuck.
4. Simulate clearing a stuck print job as a potential troubleshooting step.
5. Simulate submitting a test print to check whether printing resumes.

## Findings
- Status: Simulated — not verified on a physical printer or production system.

- For this practice scenario, assume the investigation identifies a stuck print job in the simulated print queue. The job is treated as the suspected cause of the    printing issue. No physical printer or actual print queue was accessed.

## Resolution
- Technical outcome: Simulated.

- The simulated resolution is to clear the stuck print job and submit a test print. A successful test print is assumed for this training scenario and has not been    independently verified.

- ServiceNow incident state: Pending — to be recorded after checking the actual ticket.

- Technical resolution: Simulated for learning purposes.

- Verification: No physical test print performed.

## Skills Practiced
Incident tracking, structured troubleshooting,
customer communication, and resolution documentation.

## Scenario 2 — PDF Reader
- Incident number: INC00100012
- Symptom: PDF reader closes immediately after launch.
- Investigation: Gather symptoms and check for an error message.
- Simulated troubleshooting: Restart the application and workstation.
- Simulated outcome: Application opens successfully.
- Actual ServiceNow state: In Progress
- Limitation: No real application was diagnosed or repaired.

## Scenario 3 — Network Connectivity
- Incident number: INC00100013
- Symptom: Workstation cannot access the network.
- Checks considered: Adapter status, IP configuration,
  and connectivity to an approved test destination.
- Simulated finding: Incorrect IP configuration.
- Simulated outcome: Initial attempt did not restore connectivity.
- Next action: Further investigation or escalation.
- Actual ServiceNow state: In Progress

## Learning Outcome
Practiced documenting incomplete troubleshooting and
keeping an incident active when the issue remains unresolved.
