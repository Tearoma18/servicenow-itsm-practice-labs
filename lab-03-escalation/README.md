
# Lab 03: Security-Aware Incident Escalation

## Objective
Practice documenting a simulated security-related report
and preparing an appropriate support handoff.

## Scenario
A fictional user reports an unrecognized login notification.

## Incident Details
- Incident number: INC001000111
- Short description: User reports an unrecognized login notification
- Urgency: 1 - High
- State: In Progress

## Initial Assessment
- The report may indicate an account-security concern.
- The cause has not been verified.
- No account compromise is assumed to be confirmed.
- The report should be handled cautiously and reviewed through authorized security procedures.

## First-Line Support Actions
1. Record the user's report in the incident ticket.
2. Avoid requesting passwords or authentication codes.
3. Avoid accessing accounts without authorization.
4. Follow the organization's security escalation procedure.
5. Keep the incident active pending appropriate review.
6. Document the actions taken without claiming that the account was compromised.

## Escalation Handoff
- Reason: Potential unauthorized account access.
- Requested action: Review the login notification through authorized security processes and determine whether further investigation is required.
- Assignment group: Unavailable in this ServiceNow instance; no assignment group field was visible on the incident form.
- Handoff status: Escalation documented for practice. A formal assignment or handoff could not be verified because the available form does not provide an         assignment group field.

## Outcome
- Status: Simulated security scenario — no real security event investigated.
- The fictional report was documented as an incident for training purposes. The incident number, urgency, and state will be recorded after the ticket is created    and checked in ServiceNow.
- No account investigation, containment action, or formal security-team escalation was performed. The potential security concern remains unverified, and the scenario demonstrates how first-line support can document a report and identify the need for authorized review.

## Skills Practiced
- Incident documentation, security awareness, urgency assessment, responsible handling of authentication information, escalation planning, and accurate handoff documentation.

## Disclaimer
This is a simulated scenario. No actual security incident
or account compromise is being investigated.
