# ServiceNow ITSM Practice Labs

## About This Project

This repository documents my hands-on practice with ServiceNow
IT Service Management (ITSM) using a Personal Developer Instance.

The project focuses on common IT service desk workflows,
incident management, troubleshooting documentation, and
security-aware incident escalation.

## Project Objectives

- Practice creating and managing incident tickets.
- Learn to document issues and customer communications.
- Develop structured IT troubleshooting documentation.
- Understand incident states and escalation decisions.
- Build practical IT support skills through simulated scenarios.

## Labs

### Lab 01 — Incident Management
Practice incident creation, urgency selection, state changes,
and customer-visible comments.

### Lab 02 — IT Troubleshooting
Document simulated printer, software, and network issues,
including investigation steps and outcomes.

### Lab 03 — Security-Aware Escalation
Document a simulated suspicious-login report and prepare
an appropriate incident handoff.

## Tools Used

- ServiceNow Personal Developer Instance
- GitHub
- Markdown

## Disclaimer

All scenarios are for educational purposes and use fictional
incidents. Simulated results are clearly identified.
No real customer data or confidential information is included.
